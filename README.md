# NASA Projects

This repository documents my contributions to two NASA DEVELOP research projects and the Earth-observation (EO) data extraction and processing workflows used to prepare environmental datasets for GIS analysis.

## Projects

- [Air Quality & Public Health — El Salvador](air-quality-el-salvador/): satellite aerosol optical depth (MODIS/VIIRS), available in-situ measurements, PM2.5, and regression analysis in R. Original regression scripts and outputs have not yet been added.
- [Water Resources & Mesquite Forest Change — Lambayeque, Peru](water-resources-lambayeque/): NDVI, precipitation, and soil-moisture time-series analysis related to mesquite forest decline. Original time-series scripts and outputs have not yet been added.
- [EO Data Extraction and Processing](eo-data-extraction-and-processing/): shared processing methods, including the original MODIS NDVI HDF-to-raster extraction example and an updated command-line version.

During the NASA DEVELOP work, I helped automate extraction and preparation of more than 900 multidimensional Earth-observation files for integration into ArcGIS Pro. The source script included here documents **one example of the processing stage**; it does not demonstrate downloading data from NASA servers, processing all sensors, or completing either project's final analysis.

The datasets and full historical analytical outputs are not currently included. I will add original figures and scripts as they become available.
